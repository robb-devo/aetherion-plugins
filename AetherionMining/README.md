# AetherionMining

**Zuständig für:** Amethyst Area (`aether_veins`) dig zones, spawn protect, 24h dig reset, WorldGuard open+spawn region, vein NPCs, ore seal/regen for other mines (`MiningListener`, `MiningRespawnTimes`).

**Nicht zuständig für:** Pickaxe/armor stats, recipes, skill XP, fortune payouts (→ AetherionItems `HarvestListener` / `HarvestAccess`). BreadBuilds hub paste. Pets / WildlifeLooks.

See [docs/OWNERSHIP.md](../docs/OWNERSHIP.md) and [docs/AMETHYST_AREA.md](../docs/AMETHYST_AREA.md).
