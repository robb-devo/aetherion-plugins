# AetherionMining

**Zuständig für:** The Veins world, `/mines`, entry/exit, reset timer, WorldGuard hub protection, vein NPCs, ore seal/regen (`MiningListener`, `MiningRespawnTimes`).

**Nicht zuständig für:** Pickaxe/armor stats, recipes, skill XP, fortune payouts (→ AetherionItems `HarvestListener` / `HarvestAccess`).

See [docs/OWNERSHIP.md](../docs/OWNERSHIP.md).
