# Opus / Claude prompt hygiene (STANDING)

**Robbi rule — not optional.**

## Deliverable = code + assets only

- Edit the real source tree directly (or one worktree checkout).
- **No** `_something_ship/` folders unless Robbi explicitly asks.
- **No** hash-guarded apply scripts, MANIFEST.tsv, DryRun theaters, CRLF test matrices.
- **No** README / piece tables / “honest documentation” essays.
- **No** generator-docs, regenerate notes, or “how to compile” novels.
- Compile only if Robbi asks (or you can do it without begging for `.m2` / network). If blocked → skip compile, say so in one line, stop.
- **Never deploy** unless Robbi asks.

## Token discipline

- Do the task. Stop.
- Don’t invent process around the task.
- Don’t restate the whole monorepo policy in every reply.
- Quota empty → wait → continue work. Don’t burn tokens on packaging cosplay.
